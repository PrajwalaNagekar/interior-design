# Quotation Builder — Deploy to Vercel

1. Push this folder to a GitHub repo.
2. In Vercel: Add New → Project → import the repo.
3. Framework preset: "Other". Build command: `npm run build` (or `bun run build`). Output: leave default.
4. Deploy. The build auto-targets Vercel (VERCEL=1 is set by Vercel).

Local: `npm install` then `npm run dev`.
